# Anzug-Bild

Lege hier ein Bild als `suit.png` ab (oder `.jpg` umbenannt in `suit.png`), dann
trägt der freigestellte Spieler statt des weißen Stoffs dieses Bild als Anzug.

- Am besten eine **Vorderansicht** des Anzugs, die das Bild weitgehend ausfüllt.
- Das Bild wird auf den Körper des Spielers gestreckt und bewegt sich mit ihm;
  Kopf, Hände und Stift bleiben frei.
- PNG mit Transparenz ist erlaubt: durchsichtige Stellen bekommen die
  Durchschnittsfarbe des Anzugs.
- Ohne `suit.png` wird der weiße Standard-Anzug verwendet.
